# 架构概览

```text
语音 / 文本 / Live
        |
Electron / React 桌面端
        | 固定 IPC 与版本化协议
.NET Velia Core
        |-- 共享任务调度与上下文
        |-- 模型、ASR、视觉和网页服务
        |-- Windows 应用、文档与文件工具
        |-- 操作目标绑定、结果验证与取消
        |
Chrome 扩展（经桌面端的本机认证网关连接）
```

React 界面运行在隔离且启用 sandbox 的渲染进程中。它通过固定 preload 接口访问功能，不提供任意 Shell 或任意 Core RPC 调用入口。Core 持有服务凭据并负责工具策略、任务状态、窗口与文件操作。

普通对话和 Live 任务复用 Core 的共享执行管线。浏览器工具优先使用页面结构和固定操作，Windows 文档与应用工具优先使用本地接口；受限视觉定位用于补充界面操作。

浏览器页面、屏幕文字和文档内容均作为不可信数据处理，不能仅凭其中的文字扩大用户授权。操作结果应来自实际工具验证。停止、取消和连续指令由任务与音频状态共同协调。

本仓库不包含产品激活、设备许可证或签发系统。源码许可仅约束代码使用与分发，不参与运行时功能控制。
